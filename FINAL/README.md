# GreenTech Solutions Final Website

## Project Description
This project is a multi-page website for GreenTech Solutions, a startup that provides eco-friendly technology solutions for small and medium-sized businesses. The site explains the company's mission, products, resources, and contact information.

## Purpose and Target Audience
The purpose of the website is to inform, educate, and convert visitors into potential customers. The primary audience is small to medium-sized businesses that want to reduce their carbon footprint. The secondary audience is environmentally conscious individuals interested in sustainable technology.

## Pages Included
- `FINAL.html` - Homepage
- `about.html` - Company story and milestones
- `products.html` - Products and services with search/filter
- `resources.html` - Blog/resources and newsletter signup
- `contact.html` - Contact form and company information
- `styles.css` - External CSS stylesheet
- `script.js` - JavaScript interactivity

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Responsive design using CSS media queries
- Accessibility features including alt text, skip link, labels, and high contrast mode

## Setup Instructions
1. Place all files inside the `FINAL` folder in the GitHub repository.
2. Create an `images` folder inside the `FINAL` folder.
3. Add image files with these exact names:
   - `green-technology.jpg`
   - `team-sustainability.jpg`
   - `energy-device.jpg`
   - `recycling-system.jpg`
   - `carbon-dashboard.jpg`
   - `sustainability-consulting.jpg`
4. Open `FINAL.html` in a browser to view the homepage.
5. Use the navigation bar to move between pages.

## GitHub Pages Note
If GitHub Pages is enabled for the repository, the homepage file can be opened by going to the published site URL and adding `/FINAL/FINAL.html` at the end.
